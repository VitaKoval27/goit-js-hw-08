# JavaScript Libraries & Event Optimization (HW-08) 🖼️

A project focused on integrating third-party libraries, optimizing browser events, and mastering modern frontend build tools.

---

### 📝 Project Overview
This module demonstrates the transition from manual DOM manipulation to using specialized libraries for enhanced UI/UX. The main task was to create an interactive image gallery that supports modal windows, keyboard navigation, and smooth transitions.

### 🔑 Key Implementations & My Work:
- **Event Delegation:** Optimized performance by attaching a single event listener to a parent element instead of individual images.
- **Library Integration:** Successfully integrated and configured **SimpleLightbox** for displaying high-resolution images in a modal window.
- **Data Attributes:** Used `data-` attributes to store and retrieve metadata from HTML elements dynamically.
- **Dependency Management:** Managed project packages and scripts using **npm** and `package.json`.
- **Preventing Default Behavior:** Handled form submissions and link clicks to ensure smooth, non-reloading transitions within the application.

---

### 🚀 Learning Outcomes
* Working with **external libraries** via CDN or npm modules.
* Understanding the concept of **bubbling and capturing** in event propagation.
* Basic project bundling and development environment setup with **Vite**.
* Implementing accessible UI components (handling the `Escape` key to close modals).
